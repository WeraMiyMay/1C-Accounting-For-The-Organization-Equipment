# Подсистема учета и движения ИТ-оборудования (1С:Предприятие 8.3)

## Описание проекта

Проект представляет собой готовую конфигурацию (с возможностью адаптации в формате **Расширения** для типовых баз, таких как *1С:Бухгалтерия 3.0* или *1С:УНФ*), предназначенную для автоматизации сквозного учета ИТ-активов, оргтехники и офисного оборудования в коммерческих организациях.

**Бизнес-ценность решения:**
Обеспечивает полный жизненный цикл оборудования (от закупки до утилизации), исключает утерю материальных ценностей за счет жесткого контроля остатков и персональной ответственности сотрудников, а также предоставляет руководству оперативную аналитику по ИТ-инфраструктуре компании.

---

## Архитектура и технические решения

При проектировании конфигурации основной упор был сделан на оптимальное использование ресурсов платформы, транзакционную безопасность и чистоту кода.

### 1. Схема данных и метаданные

* **Справочники:**
* `Номенклатура оборудования` — иерархический классификатор (типы устройств, модели, характеристики).
* `Инвентарные объекты` — подчинен номенклатуре. Хранит уникальные серийные/инвентарные номера конкретных физических единиц техники.
* `Поставщики`, `Сотрудники`, `Подразделения` — аналитические разрезы учета.


* **Регистры накопления:**
* `Остатки оборудования` (Тип: **Остатки**). Хранит актуальные данные в разрезе: *Подразделение*, *Сотрудник*, *Номенклатура*, *ИнвентарныйНомер*.



### 2. Документооборот и транзакционная логика

В системе реализовано три ключевых документа, двигающих регистр остатков:

1. **Поступление оборудования:** Оприходует технику на баланс организации (формирует приходные движения по регистру).
2. **Передача оборудования:** Отражает выдачу техники конкретному сотруднику с одновременным перемещением ответственности и фиксацией его подразделения.
3. **Списание оборудования:** Отражает утилизацию или выход техники из строя.

**Технические особенности проведения:**

* Реализован **оперативный контроль остатков** при проведении документов «Передача» и «Списание». Блокировка транзакции на уровне сервера базы данных при попытке списать/передать технику, которой физически нет на балансе или за данным сотрудником.
* Защита от некорректного ввода: проверка уникальности инвентарных номеров при записи документов.

### 3. Аналитическая отчетность (СКД)

Все отчеты построены на базе **Системы компоновки данных (СКД)** с использованием передовых практик разработки:

* Оптимальные запросы к виртуальным таблицам остатков (`РегистрНакопления.ОстаткиОборудования.Остатки`) с наложением параметров в фигурных скобках `{}` для быстродействия СУБД.
* Настройки компоновки включают гибкие группировки (по подразделениям/сотрудникам), условное оформление (выделение статусов) и вывод детальных графиков по динамике списаний.

## Навигация и интерфейс (UX/UI)

Интерфейс спроектирован по стандартам **«1С:Совместимо»**:

* Использован современный интерфейс **«Такси»**.
* Настроена логическая подсистема «Учет оборудования» с распределением прав и ролей.
* Рабочий стол (начальная страница) адаптирован под ключевые роли пользователей (кладовщик / системный администратор), предоставляя быстрый доступ к созданию документов и ключевым отчетам в один клик.

## Перспективы развития проекта

Проект подготовлен к масштабированию под требования enterprise-сектора:

* [ ] **Переход на модель расширения:** Адаптация подсистемы под бесшовное внедрение в типовую *1С:Бухгалтерию 3.0* (заимствование типового справочника `ФизическиеЛица` вместо самописного `Сотрудники`).
* [ ] **История перемещений:** Создание периодического регистра сведений для хранения истории ремонтов и сервисного обслуживания каждого инвентарного объекта.
* [ ] **Автоматизация инвентаризации:** Интеграция с ТСД (терминалами сбора данных) и генерация/распознавание штрихкодов/QR-кодов напрямую из карточки оборудования.

## Установка и развертывание

1. Создайте пустую информационную базу на платформе **1С:Предприятие 8.3**.
2. Запустите базу в режиме **Конфигуратор**.
3. Выполните команду `Конфигурация` -> `Загрузить конфигурацию из файла...` и выберите файл `.cf` из данного репозитория.
4. Нажмите `F7` (Обновить конфигурацию базы данных).
5. Запустите отладку (`F5`) для работы в режиме «1С:Предприятие».
