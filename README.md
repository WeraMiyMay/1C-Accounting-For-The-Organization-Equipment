# Система учета оборудования в организации

## Описание проекта

Данный проект представляет собой учебную конфигурацию на платформе 1С:Предприятие, предназначенную для автоматизации учета оборудования в организации. Система позволяет регистрировать поступление оборудования, передачу сотрудникам, списание и формирование отчетов по текущему состоянию оборудования.

Проект разработан в целях практического освоения механизмов платформы 1С:Предприятие, включая работу со справочниками, документами, регистрами накопления и отчетами.

## Функциональные возможности

1. Учет оборудования

   * хранение информации об оборудовании в справочнике
   * учет характеристик и наименований оборудования

2. Работа с поставщиками

   * выбор поставщика из справочника
   * хранение данных о поставщиках

3. Документы

   * Поступление оборудования
   * Передача оборудования сотруднику
   * Списание оборудования

4. Регистры накопления

   * учет движения оборудования
   * хранение информации о переданном и списанном оборудовании

5. Отчеты

   * список оборудования
   * оборудование у сотрудников
   * списанное оборудование
   * возможность отбора по полям

## Используемые объекты конфигурации

* Справочники

  * Оборудование
  * Поставщики
  * Сотрудники

* Документы

  * Поступление оборудования
  * Передача оборудования
  * Списание оборудования

* Регистры накопления

  * Учет оборудования

* Отчеты

  * Отчет по остаткам оборудования
  * Отчет по переданному оборудованию

## Установка и запуск

1. Открыть платформу 1С:Предприятие в режиме Конфигуратора.
2. Загрузить файл конфигурации (.cf) или выгрузку (.xml).
3. Обновить конфигурацию базы данных.
4. Запустить базу в режиме Предприятие.

## Назначение проекта

Проект предназначен для обучения и демонстрации навыков разработки на платформе 1С:Предприятие. Может использоваться как основа для дальнейшего расширения функциональности.
